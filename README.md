# QA Assistant Demo

QA Assistant es una solución inteligente basada en IA que genera y valida casos de prueba a partir de historias de usuario y código fuente, acelerando el ciclo de desarrollo y elevando la calidad del software.

## ¿Qué hace QA Assistant?
- **Genera automáticamente casos de prueba** a partir de historias de usuario (texto, archivos o generadas vía integración).
- **Valida la cobertura de pruebas existentes** comparando código, historias de usuario y matrices de casos de prueba (Excel, CSV, Google Sheets).
- **Sugiere casos de prueba faltantes** y prioriza su importancia.
- **Se integra con sistemas de generación de historias de usuario** para cubrir escenarios donde no existen HU formales.
- **Permite parametrizar** el análisis y la generación de pruebas por lenguaje, framework y tipo de test.

## Beneficios
- Reduce el tiempo y esfuerzo manual en QA.
- Mejora la cobertura y calidad de las pruebas.
- Disminuye errores en producción y retrabajo.
- Facilita la colaboración entre QA, desarrollo y líderes técnicos.

## Público objetivo
- Ingenieros de QA (manual y automatización)
- Desarrolladores
- Líderes técnicos
